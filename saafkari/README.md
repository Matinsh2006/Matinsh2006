# سایت مغازه صافکاری و نقاشی خودرو

سایت کامل مغازه صافکاری با **Django** در بک‌اند و **HTML + CSS + Tailwind + JavaScript** در فرانت‌اند.
تمام رابط کاربری راست‌چین (RTL)، فارسی و بر پایه‌ی **تقویم شمسی** است.

## راه‌اندازی سریع

```bash
# ۱. نصب وابستگی‌ها
pip install -r requirements.txt

# ۲. ساخت فایل تنظیمات
cp .env.example .env        # مقادیر را ویرایش کنید

# ۳. ساخت پایگاه داده
python manage.py migrate

# ۴. ساخت حساب کارفرما (مدیر سایت)
python manage.py create_owner --phone 09121234567 --name "نام شما"

# ۵. پر کردن سایت با داده‌های نمونه (اختیاری)
python manage.py seed_demo --with-images

# ۶. اجرا
python manage.py runserver
```

سپس:

- سایت: <http://127.0.0.1:8000/>
- پنل کارفرما: <http://127.0.0.1:8000/panel/>
- پنل پیشرفته جنگو: <http://127.0.0.1:8000/admin/>

### ساخت فایل استایل (Tailwind)

فایل ساخته‌شده (`static/css/tailwind.css`) در مخزن موجود است؛ فقط اگر قالب‌ها را تغییر دادید دوباره بسازید:

```bash
npm install          # فقط بار اول
npm run build:css    # ساخت نهایی و فشرده
npm run watch:css    # ساخت خودکار هنگام توسعه
```

## پنل پیامکی (کد تایید)

ورود کاربران با **کد یک‌بارمصرف پیامکی** انجام می‌شود؛ رمز عبوری برای مشتری وجود ندارد.

در حالت توسعه، مقدار `SMS_BACKEND=console` است و کد تایید در ترمینال چاپ می‌شود، پس بدون خرید پنل هم می‌توانید کل مسیر را آزمایش کنید.

برای راه‌اندازی واقعی، در فایل `.env`:

```ini
SMS_BACKEND=kavenegar      # یا smsir یا ghasedak
SMS_API_KEY=کلید-پنل-شما
SMS_SENDER=شماره-خط-شما
SMS_TEMPLATE=نام-الگوی-کد-تایید
```

پنل‌های آماده در `accounts/sms.py`: **کاوه‌نگار**، **sms.ir**، **قاصدک** و حالت **console**.
برای افزودن پنل تازه کافی است از کلاس `BaseSMSBackend` ارث‌بری کنید و متد `send` و `send_otp` را بنویسید.

**نکات امنیتی پیاده‌سازی‌شده:** کد به صورت هش‌شده ذخیره می‌شود، مهلت اعتبار دارد (پیش‌فرض ۲ دقیقه)،
تعداد تلاش ناموفق محدود است، فاصله‌ی زمانی بین دو ارسال و سقف ارسال در ساعت کنترل می‌شود.

### تغییر شماره موبایل (نام کاربری)

کاربر در `/account/profile/phone/` شماره‌ی جدید را وارد می‌کند، کد تایید به **شماره‌ی جدید** ارسال می‌شود
و تنها پس از تایید، نام کاربری عوض می‌شود. پیامک اطلاع‌رسانی هم به شماره‌ی قبلی ارسال می‌گردد.

## درگاه پرداخت (بیعانه)

```ini
PAYMENT_GATEWAY=sandbox    # درگاه آزمایشی داخلی، بدون نیاز به مرچنت‌کد
# یا پس از گرفتن مرچنت‌کد:
PAYMENT_GATEWAY=zarinpal
ZARINPAL_MERCHANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
ZARINPAL_SANDBOX=False
```

- **درگاه آزمایشی (`sandbox`)**: صفحه‌ای شبیه درگاه بانکی نشان می‌دهد تا کل چرخه‌ی
  «رزرو ← پرداخت بیعانه ← بازگشت و تایید ← رسید» پیش از خرید درگاه قابل آزمایش باشد.
- **زرین‌پال**: پیاده‌سازی کامل API نسخه ۴ (درخواست و تایید پرداخت).
- افزودن درگاه تازه: ارث‌بری از `BaseGateway` در `payments/gateways.py` و نوشتن دو متد
  `request_payment` و `verify`.

با پرداخت موفق بیعانه، وضعیت نوبت به‌صورت خودکار «تایید شده» می‌شود.

## رزرو نوبت با تاریخ شمسی

- تقویم شمسی **بدون کتابخانه‌ی خارجی** نوشته شده است: `static/js/persian-datepicker.js`
  و معادل پایتونی آن `core/jalali.py` (هر دو با تست‌های تطبیقی راستی‌آزمایی شده‌اند).
- روزهای تعطیل مغازه و روزهایی که ساعت کاری ندارند در تقویم **غیرفعال** می‌شوند.
- ساعت‌های خالی به‌صورت زنده از سرور گرفته می‌شود (`/appointments/slots/`) و با توجه به
  **مدت زمان خدمت**، **ظرفیت هم‌زمان مغازه** و نوبت‌های رزروشده محاسبه می‌گردد.
- تاریخ در پایگاه داده میلادی ذخیره و در همه‌جای سایت شمسی نمایش داده می‌شود.

### عکس‌های خودرو

در گام چهارم فرم رزرو، برای هر زاویه یک باکس جدا وجود دارد:
**جلو، عقب، سمت چپ، سمت راست، نمای نزدیک آسیب، سقف/کاپوت و سایر.**
هر عکس پیش از ارسال پیش‌نمایش می‌شود؛ تعداد و حجم عکس‌ها از `.env` قابل تنظیم است.

## نمونه‌کارها (قبل و بعد)

هر نمونه‌کار می‌تواند **هر تعداد** عکس داشته باشد و هر عکس با برچسب
«قبل از انجام کار»، «حین انجام کار» یا «بعد از انجام کار» ذخیره می‌شود.
در صفحه‌ی نمونه‌کار، عکس‌های قبل و بعد در دو ستون روبه‌روی هم نمایش داده می‌شوند.

## پنل کارفرما

آدرس `/panel/` — ورود با شماره موبایل و رمز عبور (`accounts:staff_login`).

از این پنل می‌توانید بدون دانش فنی این کارها را انجام دهید:

- تایید/رد نوبت‌ها، ثبت برآورد هزینه و یادداشت (با ارسال پیامک خودکار به مشتری)
- افزودن و ویرایش خدمات و دسته‌بندی آن‌ها
- درج بنر برای اسلایدر و میانه‌ی صفحه نخست
- ثبت نمونه‌کار با چند عکس قبل و بعد
- نوشتن مقاله
- ثبت لوکیشن مغازه و لینک شبکه‌های اجتماعی
- تنظیم ساعت کاری هفته، ظرفیت هم‌زمان و روزهای تعطیل
- مشاهده‌ی تراکنش‌های بیعانه، مشتریان و پیام‌های فرم تماس

## نکات انتشار (Production)

۱. در `.env` مقدار `DJANGO_DEBUG=False` و `DJANGO_SECRET_KEY` تصادفیِ بلند بگذارید.
۲. `DJANGO_ALLOWED_HOSTS` و `DJANGO_CSRF_TRUSTED_ORIGINS` را با دامنه‌ی خود پر کنید.
۳. دستورهای زیر را اجرا کنید:

```bash
npm run build:css
python manage.py collectstatic --no-input
python manage.py migrate
gunicorn config.wsgi:application --bind 0.0.0.0:8000
```

۴. پوشه‌ی `media/` را با وب‌سرور (nginx) سرو کنید و از آن پشتیبان بگیرید.
۵. برای پایگاه داده‌ی حجیم‌تر، به‌جای SQLite از PostgreSQL استفاده کنید.
۶. در حالت تولید، تنظیمات امنیتی (HSTS، کوکی امن و ریدایرکت HTTPS) به‌صورت خودکار فعال می‌شوند.

FAQ

Questions and answers

Do I need to know a framework?

No. If you know basic HTML and CSS you can use Featherkit. JavaScript is only used for small interactions.

Can I use it for client work?

Yes. Use it for personal sites, client projects and anything else you build.

Does it work without internet?

Yes. Everything is local, so pages open straight from your device with no connection.

How do I change the colors?

Each theme is a short list of CSS variables at the top of the stylesheet. Change them once and the whole site follows.
